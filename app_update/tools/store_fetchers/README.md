# Тесты для Source Fetchers 

## ⚠️ Важно

**Эти тесты НЕ должны запускаться в автоматических CI/CD пайплайнах**, так как они:
- Делают реальные HTTP запросы к внешним API (Google Play, App Store, RuStore)
- Зависят от внешних сервисов и их доступности  
- Могут быть медленными (до 30 секунд на тест)
- Могут временно не работать из-за изменений в API внешних сервисов
